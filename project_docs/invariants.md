# Invariants

This project's own rules. They hold in every layer and every epic, business and
technical alike. They are not requirements to be traded off: code that breaks
one is wrong, not unfinished. The global rules, G1 to G3, are loaded into every
session from the devcontainer template and are not repeated here.

To break one, amend this file first.

---

## Adding a rule

A rule belongs here only if it holds everywhere in this project, with no
exceptions. A rule that holds in every project belongs in the template's global
invariants. A rule with exceptions is a guideline and belongs somewhere else.

Number it and state it as a command in the heading. Underneath, say what it
means concretely in this project's own terms, and why the shortcut around it is
the bug rather than a convenience.
